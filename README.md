# fabiotorricelli.com.br

Primeira versão do site profissional do Dr. Fábio Torricelli.

## Publicar no GitHub Pages
1. Faça upload de `index.html` e `style.css` na raiz do repositório.
2. Abra Settings > Pages.
3. Em Build and deployment, selecione `Deploy from a branch`.
4. Selecione `main` e `/(root)`, depois Save.
